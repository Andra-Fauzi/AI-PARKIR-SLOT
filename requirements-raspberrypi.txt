# requirements-raspberrypi.txt

# Target: Raspberry Pi (4/5), CPU-only, TANPA GPU/CUDA
# ============================================================
#
# SYARAT WAJIB:
#   - Raspberry Pi OS 64-bit (ARM64/aarch64). Wheel PyTorch & onnxruntime
#     modern TIDAK tersedia untuk OS 32-bit (armhf). Cek dengan:
#         uname -m   -> harus muncul "aarch64", bukan "armv7l"
#
# CATATAN INSTALASI:
#   Beberapa package (torch, opencv, onnxruntime) build dari source di RPi
#   bisa SANGAT lama/gagal kalau ambil dari PyPI biasa. Disarankan pakai
#   piwheels (repo wheel prebuilt khusus ARM Raspberry Pi), biasanya sudah
#   otomatis terpakai di Raspberry Pi OS. Kalau belum, cek/isi di:
#       /etc/pip.conf   ->   [global] \n extra-index-url=https://www.piwheels.org/simple
#
#   Install dengan:
#       pip install -r requirements-raspberrypi.txt
#
#   Kalau install torch tetap gagal/lambat, alternatif: pakai wheel torch
#   ARM resmi dari https://download.pytorch.org/whl/cpu (torch versi CPU-only,
#   tetap perlu, karena ultralytics dependency-nya ke torch walau modelnya NCNN).
